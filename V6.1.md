# Flex Log 6.1 — Set copy and dropsets

- Swipe right across an empty set row (start on the set number or row background) to copy weight and reps from the row immediately above. It uses this workout's saved set or draft, not the previous session. Set 1 has no source. Entered values are never overwritten; drop rounds are not copied.
- D replaces the partials toggle. Tap to reveal one compact drop round; + Drop adds rounds and × removes one. Tap D again to fold the rounds away without erasing them.
- Enter all drop rounds before checking the parent set. The checkmark saves the set and its rounds together. Empty unused rounds are ignored; incomplete rounds require correction or removal. Uncheck a saved set to edit its rounds.
- Drop weights support the same plate math and notes as main sets. Drop volume contributes to the volume graph; estimated 1RM uses only the main set. Drops do not add planned sets or fatigue points, or restart separate timers.
- Drafts, backup/restore, unit conversions, and unchecking retain drop rounds. Old partial flags remain in historical records; there is no partials toggle.
- Existing final-set timer cleanup, slot history, automatic pinning, and collapse behavior are unchanged.

Validation: 90 automated tests pass, including UI event handlers for adding, removing, saving, unchecking and copying. Real-browser/mobile layout and physical phone gestures remain unverified because the browser executable is unavailable.

Deploy by replacing the app files at the same URL, closing all app windows, and reopening. The offline cache version is 6.1.0.
