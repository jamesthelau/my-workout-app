# Version 6.9 — Silent timer recovery

Expired timers are reconciled silently when the app opens or resumes. One on-screen summary shows which exercises are ready, without replaying old sounds or vibrations. Alerts more than 15 seconds late are discarded in the page, countdown worker, and notification service worker.

Fresh foreground expiries use the in-app sound/vibration. Background expiries use system notifications when the browser is still running the worker. System alerts are suppressed when an app window is visible. Existing notification cleanup and absolute timer deadlines remain intact.

Hardware settings explain the limitation: screen wake lock helps only while the app is visible. A locked phone may suspend workers, and closing the tab stops its countdown worker. Stock Chrome does not provide a supported local alarm scheduler for this PWA. This update does not guarantee screen-off or closed-tab delivery. A native Android timer implementation would be needed for OS-managed background timing; server push is another architecture but can be delayed by network and battery restrictions.
