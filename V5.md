# Flex Log V5

## Alphanumeric loads

- `45x5, 25x2 (Felt heavy)` → 275 numeric weight, `(Felt heavy)` saved note.
- `45x2, 25 felt heavy on set 3` → 115; the note’s 3 is not added.
- `red band` → text load retained in history, no invented numeric weight.
- `0` → genuine numeric zero, unchanged.

The mathematical prefix uses commas for addition and x, X or * for multiplication. Trailing notes start where the mathematical prefix ends. Commas may occur within notes. Invalid or unfinished math still asks for correction. Text is never evaluated as code and is escaped when rendered. Numeric graphs ignore text-only loads, rather than treating them as zero. Notes persist through exports, copies, unchecking and unit changes. Weight fields and saved notes wrap.

## Alternating groups

All V4 mappings remain. Both sides start due. Logging one side makes it cold; logging its counterpart immediately makes the first side due again, regardless of the interval. For the RDL group, both Back Extension and Hip Thrust must be logged after RDL to toggle back. Each logged member becomes cold independently.

Six calendar midnight boundaries since the latest log anywhere in the group reset every member to due. New training after that gap begins a fresh cycle: earlier events do not influence it. This uses local calendar dates, including across daylight-saving changes. There is no individual seven-day expiry for an active pair. Standalone cycles remain unchanged. Unchecking, Undo and cooldown reset recompute from saved history.

## Daily-complete folders

A complementary group occupies one workout slot. Completing either side fills it; the two-member side of the RDL group requires both movements. Standalone movements are required if due at the start of the current day, or if the user starts them today. A recently trained isolation does not become mandatory simply because its folder is opened. Custom alternatives may fill their parent slot.

A folder becomes cold when all its required slots are complete. A partial set sequence keeps it active; starting another optional movement also keeps it active until finished. The existing save-and-collapse workflow closes the exercise and parent and restores scroll position. The unused complementary movement stays due individually, but does not keep today’s completed folder glowing. The override is calculated per local calendar day and is not a permanent flag. Unchecking a required set removes completion. Reset Cooldowns clears the readiness epoch, including the folder override, without deleting records.

Example: Side & Rear Delts becomes cold after all planned Machine Lateral Raise and due Reverse Pec Deck sets are logged. Cable Lateral remains due for the next workout. If Reverse Pec Deck was trained yesterday, finishing the lateral choice is enough today unless the user also starts Reverse Pec Deck.
