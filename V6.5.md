# Background timers and plate math — 6.5

Rest timers keep their persisted absolute end timestamps. A dedicated timer-worker.js checks deadlines while running and requests notifications through the active service worker independently of the page's rendering. Foreground return and page resume immediately reconcile the UI. If workers are unavailable or fail, a main-thread timer provides the fallback. Stopping a rest, ending the workout and completing the final planned set synchronize cancellations to the worker.

The first successfully logged set that starts a rest requests notification permission through that user gesture. Misc → Hardware Settings also exposes notification permission. Denied permission never blocks logging. If denied, change the site's notification permission in Android Chrome settings. Notification clicks focus an open app window or open the app. Matching worker/page expiry messages are deduplicated by deadline/tag. App sound-off requests silent notifications; system notification volume and delivery remain controlled by Android.

These are best-effort alerts, not an Android alarm service. Android can freeze workers and pages, kill Chrome, suppress notifications with Do Not Disturb, or delay delivery. showNotification displays a notification when called; it cannot independently schedule an OS alarm or guarantee a chime. Keeping the app foreground with its wake lock remains the more reliable browser mode.

Weight inputs and drop rounds now accept + or commas for addition and x, X or * for multiplication. Examples: 45x2, 25 → 115; 45*2 + 25 → 115; 45x2 + 25x2, 10 → 150. Trailing notes remain separate: 45x2 + 25 (hard set 3) → numeric weight 115 and note (hard set 3). Text-only loads still work; incomplete operators are rejected. Decimal weights remain numeric without integer truncation. The parser never evaluates code or strips numbers out of free-text notes.

99 automated tests passed, covering worker deadline delays/cancellation/replacement, notification de-duplication/click handling, offline file caching, math and workout regressions. Real Android background delivery, permission prompts, sound and vibration remain unverified.
