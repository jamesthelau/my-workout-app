# Flex Log V4

Upper and Lower tabs share the same Floating Accessories exercises, logs, pins and timers. Reverse Curl is under Biceps. Adductors contains both adduction and abduction. Calves is a shared accessory folder.

## Readiness

Logging any set immediately changes the exercise state. All movements remain available to log. A paired exercise is muted until its counterpart is logged or seven local midnight boundaries pass. For RDL, both Back Extension and Hip Thrust must be logged after the latest RDL to bring it back into rotation. Each member of that two-exercise side becomes muted independently as it is logged. New/unlogged movements begin due. Standalone exercises become due after their own three or seven local midnight boundaries.

Readiness derives from history in the current reset epoch. Undo, unchecking, backup restore and Reset Cooldowns recompute it. A custom alternate tracks its own cycle independently; a pair falls back to the individual cycle if any member is deleted, hidden or changed to a three-day cycle. Parent borders glow if any available child is due, so the next complementary exercise stays visible.

## Complementary groups

- Convergent Machine Chest Press ↔ Incline Machine or DB Press
- Incline Cable Fly ↔ Pec Deck
- Chest-Supported T-Bar Row ↔ Seated Cable Row
- Half-Kneeling Cross-Body Pulldown ↔ Neutral Grip Lat Pulldown
- Cross-Body Overhead Cable Ext. ↔ Cross-Body Cable Pushdown
- Incline Dumbbell Curl ↔ Preacher Curl
- Dumbbell Hammer Curl ↔ Reverse Curl
- Hack Squat ↔ Bulgarian Split Squat
- Romanian Deadlift (Bilateral) ↔ 45-Degree Back Ext. (Bilateral) + Barbell Hip Thrust
- Machine Lateral Raise (Alternating) ↔ Cross-Body Cable Lateral (Alternating)
- Weighted Cable Crunches ↔ Hanging / Captain's Chair Leg Raise

## Daily goal

38 weekly points for seven-day exercises + 8 × 2 points for three-day exercises = 54 weekly points. Rounded up over four training days: **14 daily points**. This includes the reintroduced Reverse Wrist Extension (3 × 12–15, 0 RIR, 90 sec rest, Tier 3, three-day cycle). Edits and deletions recalculate the goal.

## Updating

Replace files at the same hosted URL. Close all app windows and reopen for the new offline cache. Existing logs, drafts, plans, setup notes, settings, folders, pins and timers are preserved; Reverse Wrist Extension is restored to the active list. Existing custom prescriptions remain intact.

Physical Galaxy S10 sound/vibration behavior requires a device check using Misc → Hardware Settings → Test.
