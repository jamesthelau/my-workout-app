# Supplement Tracker — 6.2

Open the pill button beside Settings. Check/uncheck an item to record or remove today's intake; tap its name to view exact dates and the supplied protocol. Daily and tactical checkmarks reflect the device's current local date. Midnight, foreground return and reload refresh the checklist without removing historical entries. Tactical labels show the most recent date relative to today.

Ten original protocols are preserved as personal notes. Separate evidence/safety notes flag unsupported or overstated medical claims. No dosing lockouts, automatic intake entries, or assumptions about physiological tolerance are applied.

Supplement history is included in the existing JSON export/restore and cross-tab synchronization. Older backups without supplement history remain supported. Rest timers, workout points, split navigation and exercise histories are independent.

Validation: 93 automated tests passed, including checklist/info click handlers, midnight/date logic, backup validation, and workout regressions. Real-browser rendering, touch behavior and Galaxy S10 hardware remain unverified because a browser executable is unavailable.

Update at the same hosted URL and close all app windows before reopening so the new offline cache activates. Export a backup before changing devices or clearing site data.
