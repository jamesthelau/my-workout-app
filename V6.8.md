# Version 6.8 — Clear finished rest reminders

- Returning to the app dismisses existing rest notifications, including accumulated alerts from older versions.
- Completing a set with the checkbox or swipe clears notifications for that exercise and its variations.
- Ending a workout clears all rest notifications.
- A new alert replaces the previous alert for that exercise instead of adding another notification.
- Notification delivery and dismissal are serialized. Delayed expiry messages already acknowledged in the active service worker are ignored.
- Other notifications are left alone. Dismissing an alert does not delete set history or cancel a current rest timer.

Validation: 106 automated tests pass, including selective cleanup, old notification cleanup, future alerts, duplicate delivery, and dismissal during in-flight delivery. Android notification behavior has not been tested on physical hardware.

Upload the updated files to your existing hosting location. Close all app windows and reopen to activate the new offline version. Workout data is retained.
