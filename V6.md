# Flex Log V6 — movement slots

Each original exercise is a movement slot. Add a custom alternate from its logger, then use the Variation selector to switch in place. The folder and station show one row per slot. Selection survives reloads and backups. Search can find any variation.

Variations keep their own weights, reps, drafts, progression graphs, rest settings and seat/setup memory. Existing alternate IDs and records are retained. Slot tier, category and rest cycle are shared; editing these fields on a variation changes the slot. Other prescription edits remain specific to the variation.

Logging any variation updates its slot's Cold/Due state. A/B pairs alternate immediately on logging and both reset after six inactive local calendar midnights. The RDL counterpart still requires both Back Extension and Hip Thrust. Standalone exercises retain their 3- or 7-day cycles.

Points are awarded once per movement slot per day. Completing a variation satisfies the slot; sets split between variations also count toward the default slot's daily target. When the slot is complete, its timers and pins are removed. Other slots' timers continue. The seed goal remains 54 weekly points / four workout days, rounded to 14 daily points. Adding variations does not increase it.

Folders turn cold when today's required slots are complete, counting either side of an alternating pair as today's choice. An unfinished optional slot remains outstanding. Undo recomputes the state from retained records.

Weight fields accept plate math and trailing notes: `45x2, 25 (Felt heavy)` stores numeric weight 115 and a separate note. Text-only loads are retained with a null numeric weight and excluded from numeric graphs; malformed math is rejected with an inline message. Text wraps in the weight field.

## Update

Replace the deployed files at the same URL and close/reopen all app windows. The service-worker cache is version 6.0.0. The local-storage key and compatible backup schema are retained. Export a backup from Misc before changing browser/site storage.
